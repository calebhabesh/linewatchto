# AWS lab run: 2026-10-19

A single short-lived deployment of `infra/aws-lab` to `us-east-1`. It was
applied, smoke-tested and destroyed in one session. Production stayed on
Oracle Cloud and was not touched. Account IDs, IPs and resource IDs are left out.

## Pre-flight

- The account was on the AWS Paid plan with no credits. The owner approved a
  cost of a few cents before apply.
- A $1/month budget existed, with email alerts at >$0.01 actual, 100% actual
  and 100% forecast. Month-to-date spend before the run was $0.00.
- `us-east-1` held no workload resources before the run (default VPC only).
- `terraform init`, `validate` and `plan` all passed. The plan was 21 to add,
  0 to change, 0 to destroy, and the saved plan file was applied unchanged.
- Settings: `t4g.small` (ARM64), 12 GiB encrypted gp3 root volume, 1-day S3
  artifact expiry, 1-day Lambda log retention, port 80 open to the owner's /32
  only, no public SSH (SSM only).
- The app images were the GHCR images for commit `097e32d2`. The packages were
  made public for the run because the instance pulls them anonymously.

## Image exposure check

The three GHCR packages were briefly public for this run, which exposed every
tag. After they were made private again, the images were checked for leaked
secrets:

- gitleaks v8.21.2 found no leaks in either the current repository history or
  the original pre-sanitization history (2,680 commits). 357 of the 362 tags
  were built from commits in one of those histories.
- The image configs of all tags (362 postgres, 362 backend, 351 frontend) were
  checked. Their environment variables and build commands contain no secrets.
  The only path matches came from the upstream Ubuntu base-image build.
- The postgres image never copies repository files.
- The backend jar and frontend app files of 7 tags were scanned: the oldest
  tag, the newest tag, and the 5 tags whose commits appear in neither history.
  The scan found no credentials, `.env` files, keys or raw provider payloads.
  gitleaks flagged three things in the frontend images, none of them secrets:
  Next.js per-build preview-mode and Server Actions keys (the app uses neither
  feature), and a route-parameter `key` field.
- The oldest frontend image (June 2026) contains a private workstation LAN
  address in a development setting. That address is not reachable from the
  internet, and the history sanitization had already removed it from git.
